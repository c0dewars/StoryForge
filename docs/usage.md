# Using StoryForge Pro

## From an idea to a user story

Prompt: `Use StoryForge Pro to refine this feature idea: Our customers need to download their invoices.`

The agent should clarify the user and goal; identify missing product decisions; then generate a provisional Jira-ready draft with business value, acceptance criteria, edge cases and questions. Unconfirmed details are marked as proposed or open.

## Improve an existing story

Prompt: `Use StoryForge Pro to review this Jira story using INVEST, keep the intent, and suggest better acceptance criteria: [paste story]`

## Split an epic

Prompt: `Use StoryForge Pro to split this feature into independent, end-to-end user outcomes. Explain dependencies and what should come first: [description]`

## Prepare for Jira

Prompt: `Use StoryForge Pro to produce copy-ready Jira Summary, Description and Acceptance Criteria fields. Mark all project-specific fields as unknown.`

With an authorized Jira connector: `Read issue ABC-123 and prepare an improved draft for approval. Do not make changes yet.` The example issue key is a placeholder; replace it with a real issue key.

## Review checklist

Before using outputs in delivery, confirm persona, expected value, business rules, security requirements, edge cases, team Definition of Ready/Done, any estimates, and Jira project schema. Do not interpret generated content as formally approved requirements.
