# FAQ & troubleshooting

### Do I need to know Jira?
No. The agent can explain the structure of a user story and produce copy-ready content.

### Does StoryForge Pro create issues in Jira?
Not on its own. Jira writes are only possible if the host agent offers a compatible authorized connector and the user approves the proposed changes.

### Do I need to connect my Atlassian account?
No, not for plain-text requirements refinement. Integration is optional.

### Does it decide story points or implementation estimates?
No. It explicitly marks estimates and project-specific fields as unconfirmed.

### Can it process sensitive requirements?
Minimize confidential information and follow your organization's rules for AI assistants. Any pasted sensitive content is handled by the chosen agent and its data policies, not a standalone StoryForge service.

### Is it a hosted SaaS or web application?
No. StoryForge Pro is a downloadable AI-agent instruction package with supporting reference documents, not a standalone graphical application. Screenshots in this repository are illustrative marketing mockups.

### What if the skill isn't detected?
Check that your agent supports custom skills and that the extracted directory includes `SKILL.md` plus its supporting folders. Review your agent's current installation instructions.

### Can I redistribute the ZIP?
Not through this repository. Follow the authorized marketplace purchase/license terms.
